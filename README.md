# 🍽️ Zestly – Full Stack Food Ordering Application

🔗 Live Demo: https://myzestly.vercel.app/

Zestly is a full-stack food ordering web application inspired by platforms like Zomato and Swiggy. It provides a seamless and interactive experience for users to explore food items, manage orders, and interact with a modern UI.

The project demonstrates real-world full-stack development using the MERN stack, focusing on scalability, performance, and clean architecture.

---

## ✨ Features

### 👤 User Features

* Browse food items and menus
* Add to cart and manage orders
* Responsive and modern UI
* Smooth navigation with sidebar and routing

### 🔐 Authentication

* User login and registration
* Secure authentication using JWT
* Role-based access (Admin/User)

### 🛠️ Admin Features

* Add, update, and delete food items
* Manage orders and users
* Dashboard for data control

---

## 🧑‍💻 Tech Stack

### 🌐 Frontend

* React.js (Hooks & Functional Components)

### ⚙️ Backend

* Node.js
* Express.js

### 🗄️ Database

* MongoDB (Mongoose)

### 🔐 Authentication

* JSON Web Tokens (JWT)
* Cookies / Local Storage

## ⚡ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/zestly.git
cd zestly
```

### 2️⃣ Setup Backend

```bash
cd server
npm install
npm run start
```

### 3️⃣ Setup Frontend

```bash
cd client
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create `.env` file in server:

```env
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
